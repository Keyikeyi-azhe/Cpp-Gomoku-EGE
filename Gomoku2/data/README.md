# 棋局数据

- `unfinished/`：未完成残局，扩展名 `.gsave`。
- `replays/`：已完成的整局复盘，以及联网中止时保存的未完复盘，扩展名 `.greplay`。

程序保存真实落子数据，不保存屏幕图片。目录初始为空，用户命名保存后创建文件。

文件采用UTF-8行文本：首行为格式及版本，第二行为 `NAME 名称`；其后为 `SIZE 15`、`MODE LOCAL_TWO/HUMAN_AI/ONLINE`。v2新增 `DIFFICULTY 0/1/2`（简单/一般/困难）、`HUMAN 1/2`（人机玩家颜色），然后为 `RESULT`、`TURN`、`MOVES`、逐手记录和 `END`。v1没有难度和玩家颜色字段，旧单机记录仍可读取。

坐标从0开始；黑为1、白为2；结果0表示未完成，1表示黑胜，2表示白胜，3表示平局。逐手记录为 `MOVE 手号 行 列 颜色`。回放与读档严格检查结果、回合和历史一致性。

联网复盘使用v4：`GOMOKU_LOCAL_REPLAY 4`、`MODE ONLINE`，允许`RESULT 0`表示只读的未完复盘。`HUMAN 1/2`表示保存这份记录的玩家执黑/白；房主固定黑，加入者固定白。`HUMAN`之后新增`REASON`（0未记录/1连五/2平局/3认输/4主动退出/5连接中断/6协商重开）和`STARTED`（服务端开局Unix秒时间戳）。认输记录有胜方而无五子连线，回放到最后一步才展示结果，零步认输则直接展示终局。

v1/v2/v3记录继续兼容，不推断缺少的时间或结束原因。棋谱不保存IP和连接口令。双方在各自电脑独立命名、保存和删除；记录不互相覆盖。联网未完复盘只能回放，不能从“继续游戏”恢复。本版不做断线重连。`network.ini`只用于记住连接输入，不是棋局存档，不需要随复盘分享。

所有棋局都从黑方开始；未完成局的TURN表示下一手玩家，已完成局保留最后一手落子方并不再接受落子。文件名自动生成，不直接使用用户输入；相同名称允许保存多个独立棋局。载入的残局保存时沿用名称与原路径，以临时文件原子替换；完成并确认保存复盘后，先写入复盘，再删除该残局文件。复盘播放绝不修改文件；列表永久删除必须由用户确认。
