# 使用说明

## 运行

完整下载并解压仓库，进入 `Gomoku3` 或 `Gomoku2`，双击 `Gomoku.exe`。不要直接在压缩包内运行。游戏需要兼容的 64 位 Windows；固定窗口为 1800×1350，较低分辨率可能无法完整显示。菜单预加载 90 帧图像，解码后约占 834 MiB，启动时需留出内存和加载时间。

同目录必须保留完整 `assets`。联网房主还需要 `GomokuServer.exe`，游戏会自动启动它，无需手动运行。两个版本均已保留原有程序，整理过程没有修改这些程序；源代码变更后请重新编译。

## 对弈

在“开始游戏”中选择单机对弈、人机对弈或联网对弈。单机由两人轮流操作；人机先选择难度和执棋颜色。鼠标点击棋盘交叉点落子，黑先，连续五子及以上获胜。单机悔棋撤回一手，人机悔棋按玩家一回合处理。

对局中按界面按钮悔棋、重开或退出；有保存需求时使用游戏内的退出流程。询问和命名期间棋盘锁定，需要先完成选择。

## 存档与复盘

未完成的本地棋局保存在 `data/unfinished/*.gsave`，从“继续游戏”载入。复盘位于 `data/replays/*.greplay`，从“复盘”打开；支持暂停、单步和自动播放，1x 每 3 秒一子，2x 每 1.5 秒一子。命名最多 24 个汉字，删除前请确认，删除文件不可从游戏内恢复。

联网中止记录仅可复盘，不能作为联网残局续玩。首次运行会按需创建数据目录；仓库不携带原作者的本地棋局和连接历史。

## 联网

1. 双方使用相同版本。跨网络时，先由双方自行连接并配置好 Tailscale，确保设备可互访；游戏不代管账号。
2. 房主选择“联网对弈 → 创建房间”，默认端口 5000；Windows 防火墙需要允许服务端的相应 TCP 入站。
3. 加入者输入房主可达的 IPv4 地址和相同端口。房主执黑，加入者执白，双方准备后开始。
4. 悔棋、重开需要对方同意；终局双方独立决定保存复盘，再决定是否再战。
5. 断线后只能保存本机已确认的落子或返回，不支持重连。单机回环测试可用两个独立目录运行客户端，加入地址填 `127.0.0.1`。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 缺图或启动异常 | 确认完整解压，assets 与 exe 同级，未只复制快捷方式 |
| 窗口显示不全 | 检查显示分辨率与缩放，当前程序固定 1800×1350 |
| 连接失败 | 检查版本、IP、端口、服务端、防火墙和设备互访 |
| 看不到旧棋局 | 两个版本使用各自 data 目录；仓库没有上传原作者的存档 |
| 源码中文乱码 | 按 GBK/代码页 936 重新打开源码，避免保存乱码 |

本次整理检查了文件结构和构建，不代表已经完成跨电脑联网及所有界面流程的实测。
