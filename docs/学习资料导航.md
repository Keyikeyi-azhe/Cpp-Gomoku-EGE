# 学习资料导航

## Gomoku2

下载整个 output/g2 后用浏览器打开 `index.html`。建议依次查看模块关系、函数调用、枚举使用、变量变化和操作流程。页面提供缩放、拖动、源码说明及 SVG 导出。独立矢量图位于 `SVG图/`，详细限制见 `分析报告.md` 和 `graphify-out/GRAPH_REPORT.md`。

图谱含推断关系，应结合标记和源码判断，不要将全部边当作实测调用。历史快照和报告保留原内容，部分证据含原本地路径，仅用于追溯。

## Gomoku3

浏览器打开 `output/g3/游戏全链路/Gomoku3_全游戏交互链路图.html`，也可用支持 SVG 的工具打开同目录超大链路图。阅读 `打开与阅读说明.txt` 了解操作。纸面阅读使用 `output/g3/pdf/Gomoku3_源码阅读伴侣.pdf`，文本备份和核对清单在同目录。

GitHub 不直接执行 HTML；请先完整下载。学习图和阅读伴侣对应生成时的代码，后续改动后行号和解释可能过期。仓库没有重新生成或重新验收这些历史资料。
