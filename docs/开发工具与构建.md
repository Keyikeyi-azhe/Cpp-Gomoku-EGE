# 开发工具与构建

| 工具或技术 | 用途 |
|---|---|
| C++11 | 游戏、AI、存档、客户端和服务端实现 |
| EGE 图形库 | 窗口、绘图、图片和鼠标交互 |
| Dev-C++ 5.11 | 原始 IDE，工程文件为 .dev |
| TDM-GCC 4.9.2 64 位 | 原始编译器 |
| Win32 API | 线程、窗口和文件等平台能力 |
| Winsock TCP / IP Helper | 网络传输与网卡信息 |
| Tailscale | 可选的跨网络设备互访工具，不是游戏内置服务 |
| PowerShell | build.ps1 构建辅助；玩家运行无需安装额外脚本环境 |

## IDE 构建

先在 Dev-C++ 打开对应版本的 `GomokuServer.dev` 并编译，再打开 `Gomoku.dev` 执行重新编译全部。选择 64 位工具链，配置好 EGE 头文件和库。不要把两个 main 入口放入同一个可执行程序。

源码包含 GBK 中文，工程使用 `-finput-charset=GBK` 和 `-std=c++11`。界面文字使用宽字符串及 Unicode 转义。请按原编码编辑，不要批量另存为 UTF-8。

## 脚本构建

在版本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .uild.ps1
```

原脚本固定编译器为 `D:\Dev-Cpp\MinGW64\bin\g++.exe`；若安装位置不同，需先修改脚本和 IDE 中对应路径。EGE 必须与该工具链匹配。原脚本依次构建服务端和游戏，输出覆盖各自 exe。

服务端链接 `ws2_32`；游戏另需 `iphlpapi`、`graphics`、`uuid`、`msimg32`、`gdi32`、`imm32`、`ole32`、`oleaut32`、`winmm`、`gdiplus`，具体以版本目录内脚本为准。

## 分发

至少保留 `Gomoku.exe`、`GomokuServer.exe` 和实际完整 `assets` 目录。data 可由首次使用时创建。仓库保留素材包中的 menu_playback.cpp 作为参考，示例与游戏工程分开编译。

游戏运行本身不依赖 Python。output 的 HTML 通过浏览器本地打开，PDF 用常规阅读器打开。
