# 素材与整理说明

原文件夹保留不动，仓库来自独立副本。两个版本的源代码和现有 Gomoku.exe、GomokuServer.exe 保留，源码字节编码不变，素材作为实际文件复制。

上传排除了对象文件、预编译头、IDE 布局、本地图谱缓存、重复 main.exe、本地连接配置、个人棋局和重复 ZIP。原素材 ZIP 约 188 MiB，完整解压素材已在仓库提供，故不重复提交压缩包；g2 可视化 ZIP 也由完整展开目录替代。游戏首次使用时创建自己的数据。

原版本 README 作为历史说明保留，其中涉及本机路径、目录联接或不存在的 tests 脚本时，请以仓库实际文件及新增文档为准。总体设计里的规划功能不作为实现承诺。

素材原目录没有提供可确认的统一授权文件。本次没有擅自给代码或素材附加 MIT 等开源许可证。后续需要由权利人确认来源、署名和许可后再补充。
