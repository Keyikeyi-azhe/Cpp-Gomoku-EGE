# 项目介绍

本项目以五子棋为载体，展示 Windows 图形程序中规则、界面、AI、网络和文件存储的协作。仓库同时保留两个实现版本及辅助资料，便于对照代码与流程学习。

## 目录

| 路径 | 内容 |
|---|---|
| Gomoku2/ | 拆分绘图、动作、输入及共享状态的版本 |
| Gomoku3/ | 主入口集中组织界面流程的版本 |
| output/g2/ | 交互分析页、SVG、关系数据、图谱和核对报告 |
| output/g3/ | 全游戏交互链路图、SVG、预览和 PDF 阅读伴侣 |
| 材料/gomoku-assets/ | 原素材、布局配置、使用说明及菜单播放示例 |
| 五子棋工程实现方案.md | 原始总体设计，含历史需求和后续规划 |
| docs/ | 本次补充的使用、构建、设计和阅读文档 |

两个版本均保留自己的 assets，便于单独复制目录运行。Git 可对相同内容去重，但完整下载后仍会占用多份磁盘空间。

## 已有能力

共享规则支持 15×15 棋盘及胜负判断。AI 使用后台搜索，避免搜索直接阻塞绘图；网络通过独立服务端裁决，客户端显示已确认状态。存档与复盘保留走子记录，并在读取时验证合法性。

本项目没有账号、匹配大厅、排行榜和云存档。总体方案中提到的计时、多局比赛、自动代落子和重连不应当作已交付功能。

## 版本阅读

学习模块拆分可先看 Gomoku2/main.cpp，再进入 game_input.h、game_actions.h、game_draw.h、ui_common.h。学习主流程可看 Gomoku3/main.cpp，再对照独立规则、AI、网络与存储模块。两套 output 提供静态关系图和源码快照，不是运行跟踪日志。
